# Contributing

Forks and pull requests are welcome. Please describe the Hytale version,
dependency versions, reproduction steps, and whether the issue affects
Survival, Creative, or both.

Please do not include private server addresses, player data, production
backups, or generated server configuration in issues or pull requests.

Run `scripts/build-dev.sh` with the required Hytale and Endgame & QoL paths
before submitting a change. The script compiles the plugin, validates assets,
and runs the included regression tests without deploying to a server.
